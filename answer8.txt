# Information Systems Core Requirements for 67-373

## Required Core Courses
To fulfill the requirements for the 67-373 Information Systems course, you must take and satisfy all of the following core courses:

- 67-100
- 67-200
- 67-250
- 67-262
- 67-272
- 67-373 (the course itself, and a core requirement)
- 17-313

## Elective Options Within the Core
You are also required to take one course from each of the following groups:

- Either **95-422** or **67-382**
- Either **05-391**, **05-410**, **05-452**, or **05-897**

## Prerequisite Clarification
There are no explicitly stated prerequisites for 67-373 other than its standing as one of the core courses required for the Information Systems major.

## Summary
To satisfy the Information Systems Core for 67-373, you must complete all the specified core courses and select the appropriate courses from the indicated elective groups. There are no additional prerequisites listed for 67-373 beyond its inclusion in the core curriculum sequence.
